## 🛠 Використані технології (Tech Stack)

* **HTML5** — семантична розмітка сторінки та забезпечення доступності (a11y).
* **CSS3** — стилізація елементів, використання Flexbox / Grid для адаптивної сітки, медіа-запити (Media Queries) та CSS-змінні.
* **JavaScript (ES6+)** — інтерактивність, робота з DOM-деревом, обробка подій та логіка додатку.
* **Git / GitHub** — система контролю версій та хостинг коду (GitHub Pages для деплою).

## 💡 Основні рішення та архітектура (Key Decisions)

1. **Адаптивний дизайн (Responsive Web Design):** Сторінка коректно відображається та зручна у використанні на мобільних пристроях, планшетах і ПК.

3. **Модульна структура:** Логіку, стилі та розмітку рознесено по окремих файлах (`index.html`, `style.css`, `app.js`) для полегшення підтримки.
