# Keepsake — Landing Page (Vite + Pug + SCSS)

Адаптивний лендінг креативної агенції **Keepsake**, перенесений на сучасний стек збірки з модульною архітектурою шаблонів і стилів, автоматичною оптимізацією зображень та контролем якості коду.

**Демо на GitHub Pages:** https://ShyshkoRuslana.github.io/landing-keepsake-vite/

---

## Вимоги до середовища

- **Node.js:** версія `20.x` або новіша
- **npm:** версія `10.x` або новіша

## Встановлення та команди

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки (http://localhost:5173)
npm run dev

# Генерація зображень у форматах AVIF, WebP та JPEG (400w, 800w)
npm run images

# Продакшн-збірка проєкту у папку dist/
npm run build

# Локальний попередній перегляд зібраного білду
npm run preview

# Автоформатування коду (Prettier + pug-plugin)
npm run format

# Перевірка стилів (Stylelint) та форматування (Prettier)
npm run lint
```
